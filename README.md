## 🚀 Features

- **Next.js Full-Stack Architecture**: Server-side rendering and static generation.
- **Interactive UI Components**: Powered by Radix UI, Framer Motion, and Tailwind CSS.
- **Containerized Deployment**: Multi-stage Docker build with NGINX reverse proxy configuration.

---

## 🛠️ Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🐳 Docker Deployment

```bash
docker-compose up --build -d
```
